# Arize & Echo × Sid Vij — House of Projects
Static site (no build step). 
## Deploy on Cloudflare Pages
1. Push this folder to a GitHub repo.
2. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.
3. Framework preset: None. Build command: (empty). Build output directory: `/`
4. Save and Deploy.

- `index.html` — main proposal (now includes Production setup + Content strategy sections)
- `reel-ideas.html` — filterable table of 30 reel ideas
